# AI Code Assistant Simulation Python

This Python script simulates a basic AI coding assistant. It demonstrates the core concepts of AI-powered development tools mentioned in the article, such as generating code snippets from natural language prompts, suggesting refactoring for existing code, and providing explanations. The "AI" logic uses simple keyword matching to return predefined code or explanations, illustrating the *functionality* of such tools rather than actual AI.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Follow the prompts to interact with the simulated AI assistant. Try prompts like "Generate Python function to add two numbers" or "Refactor loop to list comprehension" (and then paste a sample loop).
